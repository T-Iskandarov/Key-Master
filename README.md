# Key Master 🚀

**Key Master** is a lightweight, customizable tool designed to display keyboard keystrokes and mouse clicks on your screen in real-time. It's perfect for tutorials, presentations, and screen recording! 

*(O'zbek tilidagi ma'lumot pastda)*

---

## 🇬🇧 English

### ✨ Features
- **Display Keystrokes**: Shows any key you press on the screen.
- **Mouse Click Visualization**: Highlights left, right, and scroll clicks.
- **Spotlight Mode**: Double tap `Ctrl` to darken the screen and spotlight your mouse cursor.
- **Customizable Appearance**: Change text color, background color, font size, and on-screen position.
- **Multi-language Support**: Interface available in English, Russian, Uzbek, and Karakalpak.
- **Hotkey Database**: Save and manage your custom hotkeys and their descriptions.

### 📥 Installation
1. Download [KeyMaster_Setup.exe](KeyMaster_Setup.exe) from the repository.
2. Run the installer and follow the wizard.
3. Open the app from your Desktop or Start Menu.

### 🛠 Tech Stack
- **Framework**: .NET 8.0, WPF (Windows Presentation Foundation)
- **Language**: C#
- **Hooks**: Low-level Windows API keyboard and mouse hooks
